# 串口驱动安装助手

这是一个以 AI 风格为核心的网页界面，用于帮助用户为 Arduino Uno、Mega2560、Nano 等常见单片机开发板安装串口驱动。

## 功能特点

- 一键检测串口设备
- 支持选择驱动类型，例如 CH340、CP2102、FT232R、PL2303
- 带动画效果的安装进度条
- 中英文双语切换
- 采用现代 AI 产品风格的界面设计
- 纯前端实现，包含 HTML、CSS 和 JavaScript

## 快速开始

1. 直接在浏览器中打开 `index.html`。
2. 选择检测到的串口设备。
3. 选择对应的驱动类型。
4. 点击“开始安装”，即可查看安装进度动画。

## 浏览器说明

当浏览器支持 Web Serial API 时，页面会尝试自动检测串口；如果浏览器不支持，则自动切换到手动选择模式。
